# Final local quality corrections

Rule version: 2026-10-23.3. Production has not been updated.

Rain previously reduced scores without restricting eligibility. The model could also choose a lower-ranked eligible candidate. Both behaviors were corrected: complete-window weather restrictions run before ranking, and the final recommendation must be the highest-ranked eligible option. The model interprets constraints and selects verifiable comparative evidence; it cannot override restrictions or promote a lower-ranked option.

Rain probability cutoffs are 60% for picnic, gathering and tennis; 70% for golf, cricket and football; 80% for running, cycling, hiking and photography. Hourly precipitation cutoffs are 2 mm for picnic, gathering, tennis and golf, and 5 mm for the others. Wind cutoffs are 30 km/h for cycling, golf, picnic and gathering, and 40 km/h otherwise. These are explicit conservative planning policies, not calibrated safety thresholds. Every required forecast hour is checked. Missing essential weather makes a window insufficiently supported.

Only eligible windows can rank. Ranking uses the highest score lower bound, then midpoint, then a stable venue/time tie-break. A midpoint of 76 with bounds 70–82 can rank below a fully supported 73; an excluded 99 cannot win. Matrix cells now show score ranges when factors are missing, and the inspector explains ranking and restrictions. A manually selected comparison is distinguished from the actual recommended window.

When no eligible option remains, English and Hindi responses explicitly say no suitable option was found, clear recommendations and describe remaining scores as comparison only. Unnamed picnic/gathering features cannot be recommended. Real adapter results also require a mapped name and either a designated picnic-site tag or an appropriate mapped park/garden/recreation-ground polygon of at least 1,000 square metres. This minimum footprint is a destination-quality heuristic, not verified facilities, access or opening. Points and small landscaping polygons remain comparison-only unless designated as picnic sites. Actual OSM identifiers, source links, mapped type and access status are preserved; names are never fabricated. Better-supported destinations are prioritized before the candidate limit.

Before the latest request to skip testing, 108 local tests passed, including rain boundaries for all ten activities, later-hour rain, missing weather, unnamed/unverified destinations, all-unsuitable language and ranking overrides. The frontend build passed before the final attribution/imagery edits. A real local Bengaluru family-picnic request returned eight candidates, 94–97% start-hour rain probabilities, zero eligible options and zero recommendations. See quality-gate-live-local.json. This used local Qwen and real external environmental data, with no production inference.
